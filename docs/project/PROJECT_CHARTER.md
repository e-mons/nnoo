# NNOO Project Charter

Prepared by **David Bako, Software Developer**

## Product

NNOO is a business operating system for small and medium-sized African businesses. The first production release focuses on business setup, sales, expenses, stock, customers, suppliers, invoices, receipts, reporting, AI-assisted bookkeeping, business summaries, a first Business Health Score, a first Credit Passport, subscription billing, administration, and shared web/mobile access.

## August delivery model

- Tranche 1: Foundation, marketing, authentication, onboarding, roles, and initial administration.
- Tranche 2: Daily business operations.
- Tranche 3: AI tools, business intelligence, notifications, and agreed WhatsApp functions when external access is supplied.
- Tranche 4: Administration completion, security, testing, deployment, and handover.

## Product shape

- One combined Next.js web application.
- One React Native Expo mobile application.
- One shared Supabase backend per environment.
- Shared contracts and domain rules.
- Web hosted from GitHub on Vercel.
- Mobile builds managed through Expo.

## Product principles

Simple, real-data driven, secure, multi-tenant, auditable, mobile/web consistent, and released in small tested steps.
