# Finish Feature

1. Read the approved feature specification.
2. Confirm implementation matches scope.
3. Run the `regression-audit` skill.
4. Fix only current-feature defects or direct regressions.
5. Re-run required gates.
6. Create the acceptance report.
7. Run `project-docs-sync`.
8. Report scope, files, migrations, tests, manual checks, blockers, documentation, and the next recommended feature.
9. Stop.
