# Start Feature

1. Read `AGENTS.md` and the project state, tranche plan, feature ledger, architecture, definition of done, and relevant decisions.
2. Check Git branch and working tree.
3. Confirm the requested feature belongs to the active tranche.
4. Inspect relevant implementation files and live development schema when backend work is involved.
5. Use the `feature-delivery` skill to draft or update the feature specification.
6. List in scope, out of scope, expected files, database/API impact, web/mobile/admin impact, security cases, and acceptance tests.
7. Stop for approval before implementation when the specification is new or materially changed.
