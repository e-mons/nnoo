# Always-On Rule: Durable Project Memory

Chat context is temporary. Repository documentation is permanent.

After each feature:

- Update current tranche, feature, status, last green commit, last migration, and blockers in `PROJECT_STATE.md`.
- Update feature status and evidence in `FEATURE_LEDGER.md`.
- Add or update tests in `TEST_MATRIX.md`.
- Add a dated entry in `CHANGELOG.md`.
- Record the prompt and delivered result in `PROMPT_LOG.md`.
- Add a decision record for architecture, dependency, scope, data, or security decisions.
- Update version and security files when affected.
- Add new skills only for repeatable specialist work.

Preserve history. Never rewrite records to make the project appear cleaner.
