# Always-On Rule: Tranche and Scope Control

Use the active tranche from `PROJECT_STATE.md`.

Feature delivery order:

1. Select one Planned feature from the active tranche.
2. Write a feature specification.
3. Receive approval.
4. Implement only that feature.
5. Run quality gates.
6. Update project records.
7. Stop.

Do not start the next feature, build later-tranche work, add optional extras, replace working architecture during ordinary feature delivery, hide missing external credentials with simulation, or mark blocked work as completed.

When a feature is too large, split it into safe subfeatures and update the ledger before coding.
