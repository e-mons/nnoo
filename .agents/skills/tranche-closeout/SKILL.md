# Tranche Closeout

1. Confirm every tranche feature is Done or explicitly Deferred with approval.
2. Run the full test suite.
3. Run web production build.
4. Run mobile tests, Expo Doctor, and build checks.
5. Run database and RLS tests.
6. Run cross-platform acceptance journeys.
7. Review secrets, logs, dependencies, and audit controls.
8. Confirm migrations and generated types are current.
9. Confirm project documentation is current.
10. Create a tranche acceptance report.
11. Record a stable rollback point.
12. Request David Bako's approval.
13. Advance project state only after approval.
